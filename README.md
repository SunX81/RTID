# Real-Time and Independent Defense Against Adversarial Patch Attacks in Autonomous Driving
By Xiao Sun, Song Wang and Jucheng Yang

Code for "Real-Time and Independent Defense Against Adversarial Patch Attacks in Autonomous Driving"


# Datasets
Download the digital adversarial patch attack datasets from ModelScope (https://modelscope.cn/datasets/xpe811/RTID_datasets): ImageNet-drive (Targeted Attack, Untargeted Attack, Low-frequency patch attack), COCO-drive (TOG-patch Attack), and INRIA (T-SEA Attack).

See [example_cmd.sh](example_cmd) for examples of recommended hyperparameters.
